# Couch Potato

Swipe adjacent letters on a square or honeycomb grid. Casual word game — short sessions, fast first success, no hints.

## Game rules (engine owns these)

- Grids 4×4 / 5×5 / 6×6; topology **square** (8-way) or **hex / Honeycomb** (6-way odd-r); **no tile reuse in one swipe**
- **Rotate:** same letters, new view — **90°** CW or CCW (separate controls). Letters-only remap (never re-gen). **Square:** CSS board spin (~300ms) then remap; input locked mid-spin only — unlock on animation end (no extra beat). Glyphs **and tile face gradients** counter-rotate so letters + lighting stay screen-upright (avoids gradient snap when angle resets). **Frame chrome + box-shadow stay on non-rotating `.cp-board-frame`**; only inner `.cp-board-spin` transforms (idle `transition: none` so angle remap doesn’t reverse-spin). **Hex / reduced-motion:** instant remap (90° container spin can’t land on odd-r honeycomb).
- Tiles stay for the round (reusable across words)
- Min word length: global floor **3**; per-game setup may raise to **4** or **5**. **No artificial max** — any dictionary word that fits an adjacent no-reuse path counts (up to N² tiles on an N×N grid), including 10+ when paths exist. Lobby “3+/4+/5+” is a floor only; gen `ge5`/`ge6`/`ge7`/`ge8`/`ge10` thresholds are quality floors, not ceilings. Larger grids ask for more long finds (`BOARD_THRESHOLDS`: soft `ge10: 1` on square **5×5** / **6×6** and hex **6×6**, plus ge7/ge8; hex 5×5 stays leaner) while `ge3`/`total` still require a short-word base. Soft long floors may loosen on late retries; fallback ranking heavily prefers 8+/10+ boards when the lexicon can produce them; `ge6 ≥ 1` never loosens to 0
- No duplicate words per round
- Dictionary: [dolph/dictionary](https://github.com/dolph/dictionary) — **play lexicon = ENABLE** (`enable1.txt` − NSFW blocklist − **given-name filter** ≈ 172k words). Name filter: SSA baby-name cumulative mass ([hadley/data-baby-names](https://github.com/hadley/data-baby-names), minMass 0.05) minus `packages/dictionary/data/name-allowlist.txt` dual-use everyday English (keeps `mark`/`hope`/`grace`/`will`/…; drops `peter`/`john`/…). **`popular.txt`** (enable1 ∩ Wiktionary TV/movie frequency ≈ 25k) still ranks board-gen quality and filters Results **Long ones left** — it does **not** gate accept / `allWords` / targets / Words left. Web loads ENABLE via a **dynamic** Play import (CacheFirst after first use; ~457 KB gzip) — never idle-prefetched from the lobby (warm on Play hover/focus/click only). Blocked tokens must not appear in validation, board gen, or missed-words.
- **Board letter mix scales with difficulty** (`LETTER_VARIETY` in `config.ts`): common-biased `LETTER_WEIGHTS` get flattened per-tile (`letterMixWeights`) and already-placed letters get docked so one board doesn't over-repeat. Easy stays common-biased with just enough anti-repeat to avoid mono-vowel soup; Medium balances common + uncommon; Hard leans into rarer letters and penalizes repeats harder for real variety pressure. All modes (Goal / Timed / Survival) pass lobby difficulty into gen. Never overrides gen thresholds — a spicier mix that can't produce enough words still loses to the best-effort fallback board.
- Scoring: `points = length - 2` (config constant)
- **Goal** (UI; engine `mode: "target"`): countdown — `remaining` starts at achievable target (board max × `TARGET_RATIOS` Easy **0.30** / Med **0.40** / Hard **0.65**, then clamped by `TARGET_CAPS` Easy **48** / Med **75** / Hard **105** so crumb-dense boards don’t demand unbounded pts); each accepted word subtracts its points; **win when remaining === 0** (“Clear the couch”). Ratios are of **points** (`length − 2`), not word count — calibrated so short-first casual play hits ~p50 / ~p58 / p80 of board words on lean boards; caps break the scary correlation with huge word counts on fat 5×5/6×6. Scoring formula unchanged so Timed/Survival/medals stay stable. High scores still store **points earned**. Max/target use only words ≥ active min length. Lobby card: Goal / Clear the couch, not “High score” (collides with Timed haul / Potato Board bests).
- **Timed**: fixed board; 30/60/90/120s sprint + Easy/Med/Hard letter mix → results (score accumulates; find as many words as you can before time's up). Lobby: Timed / Nab all you can — **How hard?** + **How long?**. HUD challenge badge = difficulty (duration lives on the timer ring). High scores keyed by duration × difficulty.
- **Survival** (UI; engine `mode: "survival"`): countdown clock, no points target — starts at `SURVIVAL_START_SECONDS[difficulty]` (Easy generous, Hard stingy, `config.ts`); each accepted word refills it via `survivalBonusSeconds(points, difficulty)` = `points * SURVIVAL_SECONDS_PER_POINT * SURVIVAL_BONUS_MULTIPLIER[difficulty]`, rounded, floored at `SURVIVAL_MIN_BONUS_SECONDS` (never a 0s refill); ends `timeout` when the clock hits 0 (reuses `tickTimer`, same as Timed). Points still accumulate for haul/high scores. Difficulty picker reused from Goal (**How hard?**, not duration chips). Lobby: Survival / Keep the clock fed. High scores keyed by mode × difficulty like Goal.
- **Quit mid-game** (UI: **End run**) → results with progress so far (`won` | `timeout` | `quit`). **Early quit:** End run or Leave run within **3s** of board ready dumps the run and returns to lobby (no results / no haul / no medals) — accidental Play. **End curtain:** every finish (not just Goal win) plays a ~1.3s Play beat — tile drop + confetti + outcome pill (`Couch clear!` / `Time's up!` / `Clock ran dry!` / `Haul locked!`) + SFX (`runEndFlourish.ts`) before Results.
- **Shareable play links:** `/play` takes lobby setup as query params (`mode`, `grid`, `board`, `min`, plus `diff` and/or `time`). Examples: `/play?mode=goal&grid=5&board=hex&diff=hard&min=4`, `/play?mode=timed&grid=4&board=square&time=90&diff=medium&min=3`. `mode=goal` = engine target; `board=honeycomb` aliases hex. Lobby Play / Results Play again write the params; bare `/play` restores last launch into the URL. Helpers: `apps/web/src/playLaunchSearch.ts`.
- **Leave mid-game** (⌘K / chrome jump / back / tab close while a run is open) → warn first (`useBlocker` leave guard on Play). Confirm **Leave run** dumps the haul like Restart (no results / no medals). Within early-quit grace → lobby instead. **Keep playing** stays. Finish → `/results` is never blocked. Tab close uses the browser beforeunload prompt.
- **Restart mid-game** (Couch break **Restart**) → discard the open run (no results / no haul record) and spin a fresh board with the same lobby launch prefs
- **Pause menu** (play): Escape or HUD pause → **Couch break** overlay — choice cards for Sound effects / Lobby jam / Words left / Look, then pixel `border-t` before run controls: phone = **End run | Restart** row then full-width **Resume**; sm+ = one **End run | Restart | Resume** row. Pauses timed clock + blocks grid swipe until Resume / second Escape / Restart

- CSS motion first; no anime.js unless a real gap
- Play chrome is tactile (cream pillow tiles, sage frame) — keep iterating polish; don’t regress to flat robot UI

## Code style

TPP DRY: one authoritative place per piece of knowledge. No over-abstraction, no one-export files. Engine decides; UI displays. Format with `oxfmt`; lint with `oxlint` (see `.cursor/rules/coding.mdc`).

**Commits:** [Conventional Commits](https://www.conventionalcommits.org/) — imperative subject, concise. Types: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`; optional scope: `feat(engine):`, `fix(play):`. Examples: `fix(play): stop last-catch from shrinking the board`; `feat(engine): vary board letters by difficulty`; `docs: document shared chrome-devtools browser`; `style(ui): remove hard bezel from switch rows`. Don't rewrite history to fix old messages.

## Agent UI verification (required)

UI work is **not done** until interactively verified in a running local app (pointer swipe across tiles — not click-only). See `.cursor/skills/verify-ui`. Engine-only → Vitest; UI → Vitest **and** interactive check.

**Browser QA:** `chrome-devtools` MCP is configured (`~/.cursor/mcp.json`) to attach to one shared debuggable Chrome (`--browserUrl`, port 9222) instead of launching a new Chrome App per call — see `.cursor/skills/verify-ui` for the start script and etiquette (reuse it, don't spin up a parallel Playwright browser when devtools suffices, don't fight another run's open tabs).

**Mobile:** agent default is **Expo web** (`bun run mobile:web`) + Playwright smoke — see `.cursor/skills/verify-mobile`. Optional iOS Simulator boot when native launch matters. Full play QA remains on web until Expo play ships.

## Living agent docs

When the user locks a new decision, **self-update** `AGENTS.md` / `.cursor/rules/` / `.cursor/skills/` in the same turn — don’t wait to be asked; chat must not be the only record. See `.cursor/skills/sync-agent-docs` and `.cursor/rules/agent-docs.mdc` (always-on).
