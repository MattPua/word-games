# Expo smoke (`@couch-potato/mobile`)

Minimal Expo app that imports `@couch-potato/ui`, `@couch-potato/game-engine`, and `@couch-potato/dictionary`.

```sh
bun install
bun run mobile:web    # agent default — Playwright smoke
# or
cd apps/mobile && bun run start
```

See `.cursor/skills/verify-mobile`. NativeWind on Expo comes later.
